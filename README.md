# RYTHEM Frontend

## URL de acceso local
Después de instalar dependencias y ejecutar el servidor, la web queda disponible en:

- Desarrollo: `http://localhost:5173`
- Preview de build: `http://localhost:4173`

También está configurada para escuchar en `0.0.0.0`, por lo que puedes entrar desde otros dispositivos en la misma red usando:

- `http://<IP_DE_TU_MAQUINA>:5173`

## Comandos

```bash
npm install
npm run dev
```
